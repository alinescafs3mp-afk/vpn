# AutoVPN: исходники Astra R1

Это первый кумулятив с реализацией исправлений шестого аудита. Внутри полный проект, тесты, сценарии сборки и инструкции для Грока.

**Это ещё не готовый VPN-клиент.** Исправлены важные ошибки работы с проверками, снимками подписок, переключением, ресурсами и командами. Реальный установленный TUN, защита WFP и установщик пока не завершены. Собранные EXE помечаются DEVELOPMENT и не должны выдаваться за работающий защищённый VPN.

Гроку нужно прочитать `docs/GROK_BUILD_HANDOFF.md`, собрать проект и вернуть файлы с честным отчётом. Эта инструкция не перекладывает на него оставшуюся реализацию.

На Windows с PowerShell 7 и SDK из `global.json`:

```powershell
pwsh -NoProfile -File .\scripts\test.ps1
pwsh -NoProfile -File .\scripts\package.ps1
```

Результат: `artifacts/AutoVPN-astra-r1-win-x64-development.zip` и файл SHA-256. Для нативных проверок без TUN команды даны в handoff. Состояние реализации: `docs/ASTRA_IMPLEMENTATION_STATUS.md`.

Распаковывайте исходники в новую пустую папку. Не заменяйте ими произвольные рабочие файлы и не удаляйте существующий пользовательский каталог. Архив не содержит SDK, шрифтов, пользовательских баз, ключей, живых подписок или сетевых дампов.
