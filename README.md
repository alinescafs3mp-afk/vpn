# AutoVPN

Актуальная разработка ведётся только в `main`. Текущий срез: **V3E / 0.1.5**, подробности в `README_V3E_RU.md` и `docs/checkpoints/V3E.md`.

**Это не готовый системный VPN.** Код собран на Linux и Windows Server. Последняя шестикратная полная регрессия: Linux прошла, Windows не прошла из-за четырёх отказов в двух сценариях очистки дочерних процессов. Установка службы, привилегированная передача узла, TUN, защита DNS/IPv6 и восстановление сети ещё не приняты.

## Точки входа

- `README_V3E_RU.md`: изменения, измеренные результаты и ограничения текущего среза.
- `docs/evidence/V3E_VALIDATION.json`: точные коммиты, прогоны, счётчики и незакрытые отказы.
- `docs/checkpoints/V3E.md`: продолжение реализации.
- `docs/branch-archive/inventory.json`: происхождение сохранённых отличий прежних веток. Все их вершины доступны из истории `main`; архивные прототипы не включены в активную сборку.

Клиент предназначен для Windows. Источник узлов: публичный каталог `igareck/vpn-configs-for-russia`. Данные подписки не являются готовым доверенным профилем или доказательством работоспособности узла. Пользовательский каталог и системный режим службы разделены. Системный режим пока предоставляет только проверку состояния, не подключение.

## Сборка и проверка

SDK закреплён в `global.json`: .NET `10.0.112`.

```powershell
dotnet build AutoVpn.slnx -c Release '-p:Platform=Any CPU'
./scripts/test-v3e.ps1
```

Второй скрипт получает закреплённое ядро, проверяет хеш и запускает шесть полных серий. Он сохраняет каждый TRX и завершает работу с ошибкой, если хотя бы одна серия не прошла. Для менее длительной обычной проверки есть `scripts/test.ps1`; её состав отличается от полной нативной регрессии.

Не запускайте исторические одноразовые скрипты консолидации или интеграции повторно. Старые отчёты описывают свои коммиты и не заменяют текущий результат.

## Поставка

Установщик пока не готов. Наличие собранного EXE или успешного запуска окна не доказывает готовность туннеля. Не отключайте проверку подписи драйверов и антивирус. Диагностика службы не означает, что VPN подключён.
