# AutoVPN V3: исходный кандидат

**Статус: SOURCE CANDIDATE / NOT BUILT / NOT A VPN RELEASE.**

Продолжение подтверждённой V2 `70f9546d81ac58845c174d5dd4669dcd1fe27a5f`, версия исходников `0.1.3`.
Это первый исходный срез V3, а не готовая к запуску версия. Сборка, C#-тесты и работа на Windows в окружении этой итерации не выполнены: нет .NET SDK и доступного способа установить его с зависимостями. Прошедшие ранее проверки V2 не относятся к новому коду.

В код добавлены владелец процесса ядра с точной принадлежностью операции, повторяемая очистка, отказ от позднего запуска отменённой операции, конкретный **непривилегированный non-TUN** процесс Mihomo, проверка его хеша и локального контроллера. Брокер учитывает завершение процесса, требует идентичность двух проверочных целей и запрещает новый Connect после начала Shutdown. Исправлено ложное включение признака защиты при ошибке незащищённого подключения.

**Кнопка подключения ещё не поднимает VPN.** Производственный профиль остаётся TUN, а новый runtime сознательно отказывается запускать TUN и привилегированный Windows-процесс. Для запуска всего VPN ещё нужны согласованная передача каталога, установленная служба, защита, подтверждение пути трафика и восстановление. Обычный локальный SOCKS-listener в проверочном runtime не выдаётся за защищённую системную сессию.

Точка продолжения: `docs/checkpoints/V3.md`. Сборка и проверка для Грока: `docs/GROK_BUILD_HANDOFF_V3.md`. Код и проверки разработаны Астрой; Гроку не передаётся незавершённая реализация.

Основные команды для среды с SDK из `global.json`:

```powershell
pwsh -NoProfile -File .\scripts\test-v3.ps1
# Необязательные нативные проверки с официальным ядром:
pwsh -NoProfile -File .\scripts\test-v3.ps1 -Native -CorePath <pinned-core-path>
# Только Windows x64, после успешной проверки:
pwsh -NoProfile -File .\scripts\package-v3.ps1 -IncludePinnedCore
```
