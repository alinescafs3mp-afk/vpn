# AutoVPN: исправление жизненного цикла runtime

6 октября 2026. Независимое продолжение опубликованной V3G в main.
Это не кумулятив V3I и не включение локального кандидата V3H. Версия сборки пока 0.1.7.

## Что исправлено

Основной MihomoRuntimeProcess теперь использует тот же читатель доступных байтов,
который в V3G был подключён только к проверкам серверов. Пустой канал вывода
молчащего дочернего процесса не должен удерживать рабочий поток в блокирующем чтении.
Отдельный Windows-контроль вызывает именно читатель runtime, не только его аналог в probe.

Ранний Stop теперь запрещает будущий Start этого экземпляра. Раньше остановка
ещё не запущенного runtime помечала его завершённым, но последующий Start мог
создать процесс, который дальнейший Stop уже не обслуживал.
Остановка отменяет и дожидается начатого запуска до очистки его ресурсов.
Параллельные отключения используют одну задачу; отмена ожидания не бросает её.
Неудачная очистка остаётся неудачной и не разрешает новый запуск этого экземпляра.
Ошибки чтения вывода не становятся EOF и не раскрывают приватный текст исключения.

перезапуск, удаление и уборка собственных ресурсов. Передачу узла V3H это не проверяет.

## Что не следует из этих результатов

Локальная среда недоступна с ClientError; локальной сборки, нового Windows EXE,
самостоятельной проверки архивов и приёмки Windows 11 в этом заходе нет.
Нативные проверки всего MihomoRuntimeProcess с новым жизненным циклом выполнены на Linux;
на Windows отдельно проверен его читатель на синтетическом дочернем процессе.
Запуск от SYSTEM и TUN по-прежнему отвергаются. Правила TLS, генератор профиля,
ядро, SDK, сетевые настройки и код установленной службы не менялись.
Постоянная ошибка чтения вывода остаётся закрытым отказом очистки, не исправленной аварией.

V3H остаётся в ранее выданном отдельном архиве и не включена в main.
При последующем согласовании её тестового скрипта нельзя затереть эти 20 новых случаев.
Ожидаемый объединённый набор 731, но это пока не выполненный совместный прогон.
