# AutoVPN — как пользоваться

Окно на русском: Подключение, Серверы, Подписки, Настройки.

Сейчас окно только собирается. На Linux оно не запускалось, на Windows его не нажимали. Кнопки ниже описывают задуманное поведение кода, а не проверенный сеанс.

## Подключение

1. Прочитайте предупреждение и отметьте согласие. Без него брокер отклоняет подключение.
2. Нажмите кнопку подключения.

На этой сборке брокер не ставит фильтры и не поднимает TUN. Ответ будет отказом, фаза останется «Не подключён». Надпись «Подключено» появляется только после отдельного подтверждения рабочего канала. Это подтверждение через канал управления недоступно.

Если служба не отвечает, окно пишет, что служба недоступна, и не показывает подключение.

## Серверы

Вкладки «Рабочие», «Избранное» и «Все» пусты, пока нет локальной проверки. Страна в имени узла не считается измеренным выходом. Список публичных серверов из источника сам по себе не делает их рабочими.

## Подписки

Источник — репозиторий igareck/vpn-configs-for-russia. Минимальный интервал обновления 15 минут. Совет источника обновляться раз в минуту не исполняется. Мосты Tor в пул VPN не входят.

Обновление не должно рвать уже рабочий сеанс. Этот сценарий покрыт модульными тестами на фикстурах и не прогонялся на живом туннеле.

## Настройки

Защита при подключении и доступ к локальной сети включены по умолчанию. Небезопасные сертификаты выключены. Выключение защиты не разрешает непроверенный туннель. Закрытие окна прячет его в область уведомлений. Автозапуск и автоподключение выключены.

## Чего приложение не обещает

Оно не измеряло скорость и задержку публичных узлов. Оно не обходит проверки Windows. Оно не обновляется само.
