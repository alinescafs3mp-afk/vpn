# AutoVPN V2

V2 продолжает V1 и добавляет отдельное поддержание каталога между обновлениями подписок. Рабочий список требует двух успешных HTTPS-проверок; есть пауза, возобновление и отмена при отзыве согласия. Старые записи не удаляются и не получают новый статус без проверки.

Это версия разработки, не готовый VPN для всего компьютера. Windows-служба с TUN, защита, установщик и полноценная привилегированная передача серверов ещё не завершены.

Сборка для Грока: `docs/GROK_BUILD_HANDOFF_V2.md`. Точка продолжения: `docs/checkpoints/V2.md`. Скрипт этой версии: `scripts/package-v2.ps1`. Старые документы V1 сохранены как история, использовать для V2 нужно указанную новую инструкцию.
