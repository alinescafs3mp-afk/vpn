# AutoVPN V3B: проверенное продолжение V3

Версия исходников 0.1.3. Это **версия разработки, не готовый VPN для всего компьютера**. Исходный V3 сохранён в истории; V3B добавляет рабочие связи между его компонентами.

Брокер теперь обновляет отдельное read-only представление SQLite-каталога. Настройки, проверки и сетевая эпоха больше не остаются старым снимком, а брокер не конкурирует с интерфейсом за запись. Секреты на Windows остаются под DPAPI текущего пользователя. Это передача данных между непривилегированными компонентами одного пользователя, **не доверенная передача в службу SYSTEM**.

При замене сервера старый процесс сначала подтверждённо останавливается, затем запускается новый. Отмена, отключение, отзыв согласия и изменение политики во время остановки препятствуют позднему запуску. Ошибка очистки сохраняет владельца ресурса и допускает повторную остановку. Новый процесс ещё не означает подтверждённое соединение.

Отдельный наблюдатель отслеживает локальную доступность каталога, политику и процесс; он не запускает дополнительные сетевые проверки. При утрате разрешения процесс останавливается, но уже установленная защита не снимается автоматически. Интерфейс опрашивает фактическое состояние и при отзыве согласия явно запрашивает отключение. Автоповтор допустим только для однозначно отвергнутого запроса Disconnect со старой ревизией, максимум три попытки.

Исправлена загрузка отключённых семейств подписок. Проверка S603 снова включена в обычный прогон; поздний ответ отключённого семейства не публикуется.

В среде автора выполнены сборка всего решения без предупреждений и полный Linux-прогон с официальным Mihomo: **404 теста, 404 passed, 0 failed, 0 skipped**. Windows, WPF и пакет подтверждаются отдельными свидетельствами конкретного коммита, а не результатами Linux. Итоговые журналы и результаты сохраняются рядом с поставкой и в CI.

**Кнопка подключения по-прежнему не поднимает системный VPN.** Production TUN заблокирован до реализации установленного брокера, защиты и восстановления сети. Не регистрируйте текущий console broker как Windows-службу и не убирайте отказы для получения зелёного статуса.

Продолжение: `docs/checkpoints/V3B.md`. Гроку: `docs/GROK_BUILD_HANDOFF_V3B.md`, только сборка и проверка. Основная команда: `pwsh -NoProfile -File scripts/test-v3.ps1 -Native -CorePath <официальное-закреплённое-ядро>`.
