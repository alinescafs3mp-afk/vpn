# AutoVPN V3C: состояние Windows-службы

Версия разработки 0.1.4. База: V3B (`7d99416c01499ed69593f4c948103cf0feb0d8c0`).
Это не готовый VPN и не подтверждённая установленная служба.

Добавлены код SCM-жизненного цикла и отдельный канал только для состояния,
проверка соответствия канала процессу службы, строгие ограниченные кадры,
кнопка проверки службы в настройках и номер версии из сборки.
Системный режим не читает пользовательскую базу и не запускает Mihomo.
Команды подключения и данные серверов этот канал отвергает.

Установочные скрипты не входят в эту поставку: передачу установочного изменения
отклонил инструмент. Оно не пересылается обходным способом. Установка, запуск
под SYSTEM, ACL между учётными записями, настоящий TUN и восстановление сети
имеют статус NOT_RUN. Не регистрируйте этот срез как готовую VPN-службу.

Ветка кандидата: `implementation/astra-v3c-status`. Точная проверенная база main
остаётся V3B. Результаты текущих проверок находятся во внешнем пакете evidence;
исторические документы и результаты V2/V3/V3B не являются проверкой V3C.
Подробности: `docs/checkpoints/V3C.md`.
